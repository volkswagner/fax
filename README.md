## Fax

A Faxing System for Frappe Framework using Telnyx API.
We use Telnyx for the great service and support. If
you'd like to sign up using our [partner link](https://partners.telnyx.com/zfk4np8mjlue), please do.

Send faxes from Frappe's Desk interface.

Requires Telnyx account, DID phone number and API key.
